| **课题摘要** | 本研究设计并实现了一款基于表面肌电（sEMG）信号的疲劳预警腕带系统。硬件端以 Arduino UNO R4 WiFi 为核心，搭载 MyoWare sEMG 传感器，以 1000Hz 采样率采集肌电信号，通过 256 点 FFT 实时提取 RMS（均方根）与 MDF（中值频率）两项核心特征；校准基准与 WiFi 凭据存于片内 EEPROM（8KB Data Flash），实时时序数据经 WiFi 上送 CloudBase 云数据库。软件端采用三阶段个性化自适应模型：Phase1 静息基线在线自校正、Phase2 最大用力锚点修正与个人恢复率学习、Phase3 云端校准记忆（通过 getProfile 云函数恢复历史校准基准），解决了传统固定阈值方案在不同个体间误报率高的问题。配套微信小程序提供校准引导、实时监测（五指标 + 双曲线）、数据分析（结论卡片 + 月度热力图）三大功能。经实测，MDF 算法频率分辨率达 3.9 Hz/bin，佩戴检测采用双阈值滞回后误报率从 15% 降至 0%，端到端延迟约 320ms，满足实时预警需求。 ||||
| **引言** | 肌肉疲劳是运动损伤的主要诱因之一。传统的疲劳感知依赖主观体感，缺乏客观量化手段。表面肌电（sEMG）技术通过贴附在皮肤表面的电极采集肌肉电信号，其中的 RMS（均方根）反映肌肉激活强度，MDF（中值频率）随疲劳程度增加而单调下降——这一现象已被 De Luca[1]、Merletti[2][7] 等大量研究证实。然而，现有可穿戴 sEMG 设备大多面向专业体育科研，价格高昂且操作复杂，难以在日常运动场景普及。此外，不同个体的 MDF 基线差异可达 20~40 Hz，统一的疲劳阈值必然导致误报。为此，本课题旨在开发一款低成本、个性化自适应的 sEMG 疲劳预警腕带，让普通用户也能通过手机实时了解自身的肌肉疲劳状态。 ||||
| **方法与假设概述** | 本研究的核心假设是：「MDF 的相对变化量（相对于个人校准基准）比绝对值更能准确反映疲劳程度」。基于此假设，系统采用以下技术路线：<br><br>**硬件层**：Arduino UNO R4 WiFi（5V 14-bit ADC @1000Hz）+ MyoWare 传感器（输出 0~3V，1.5V 基准）。信号链为：原始采样→50Hz/60Hz 双陷波(Q=25)→ 去极值平均 → RMS(EMA α=0.35) / MDF(FFT 256-point) → 疲劳度公式 F=(activeMDF−curMDF)/(activeMDF−endMDF)×100%。存储方面：校准基准/个人信息/WiFi 凭据存于片内 EEPROM（8KB Data Flash，约 200B），实时时序数据（10Hz 特征帧）经 WiFi 以 HTTP 批量（每 3 秒 10 帧）上送 CloudBase 云数据库持久化，形成「端侧轻存储 + 云端海量存储」分工。<br><br>**算法层（三阶段个性化）**：<br>- Phase1 静息基线自校正：非收缩期 RMS 稳定后慢更新 relax_rms/relax_mdf（EMA α=0.02），约束在校准参考的 0.6~1.4x。<br>- Phase2 锚点修正与恢复率学习：新鲜态(activeMDF 慢抬钳 400Hz / activeRMS 约束 0.8~1.5x)；放松期从衰减率学习个人 recoveryFactor(钳 0.9965~0.9989)。<br>- Phase3 云端校准记忆：启动后拉取 getProfile（取最近一次 completed session 的校准数据）写入 EEPROM，实现垮会话持久化。<br><br>**软件层**：微信小程序四页面（校准/实时/分析/网络）；BLE 仅用于网络配置页将 WiFi 账号密码从手机下发给设备，实时数据由设备经 WiFi 直连 CloudBase HTTP 上云、小程序从云端拉取展示；配套 6 个 CloudBase 云函数(dataIngest/uploadCalibration/getProfile/reportStatus/ackCommand/uploadStats)。 ||||
| **数据记录与分析** | ### 算法验证<br><br>MDF 算法经 10 组等长收缩试验验证：线性下降斜率 -0.3±0.08 Hz/s（R²>0.91），与 De Luca[1] 报道的 -0.2~-0.5 Hz/s 范围一致[1]。256 点 FFT 使频率分辨率从 7.8 Hz/bin（128 点）提升至 3.9 Hz/bin[7]，MDF 值跳动幅度缩小约 60%。<br><br>### 佩戴检测<br><br>原单阈值方案(quality≥30)误报率 15%（6/40 次测试）；改用 m_50hzRms 双阈值滞回（enter>700mV / exit<400mV）后误报率降至 0%，检测延迟从 0.8s 增至 1.5s（可接受）[9]。<br><br>### 云端性能<br><br>dataIngest 批量合并优化后：以 10Hz 采样、每 3 秒（或满 10 帧）批量上送一次，云端写操作从逐帧 864000 次/日降至约 28800 次/日（降低约 97%），P99 延迟从 180ms 降至 45ms，费用降至免费额度的 35%。<br><br>### 端到端延迟<br><br>全链路 P99 约 320ms：WiFi/Cloud 上行 180ms + 小程序渲染 90ms + 固件处理 50ms[10]。瓶颈在无线网络上行（每 3 秒批量上送 10 帧、单帧约 400B payload），可通过增大批大小或改用设备直连小程序的本地通道进一步优化。<br><br>### 数据分析页<br><br>月度热力图去重 Bug 修复后聚合正确率 100%（4 种回归场景全覆盖）；结论卡片五级分级（F<25%/25~50%/50~70%/70~90%/>90%）经 10 名用户测试反馈清晰度评分 4.5/5。[12] ||||
| **结论概述** | 本研究成功实现了基于个性化自适应模型的 sEMG 疲劳预警腕带系统。主要贡献包括：<br><br>1. **三阶段个性化自适应算法**：首次在资源受限的 Arduino 平台上实现了完整的在线自学习疲劳监测框架，Phase1/2/3 分别解决了基线漂移、个体差异和垮会话记忆三个核心难题。<br><br>2. **工程可靠性优化**：双阈值滞回佩戴检测（误报率 0%）、CalibState 独立状态机+看门狗、EEPROM 轻存储+云端批量合并写入等一系列工程实践确保了系统在真实使用场景下的鲁棒性。<br><br>3. **完整的软硬件闭环**：从传感器→固件算法→经 WiFi 上云→云函数→小程序可视化，全链路端到端延迟约 320ms，满足实时预警需求。<br><br>**局限性**：（a）当前仅支持单通道（单块肌肉）测量，多通道融合可进一步提升精度[3]；（b）RMS 指标对电极-皮肤接触压力敏感，需改进电极固定方式或从算法上补偿[8]；（c）实时数据经云端中转，弱网环境下端到端延迟偏高，未来可评估设备直连小程序的本地通道（如 WebSocket）以降低云中转开销。<br><br>**未来工作**：（a）引入机器学习模型（如 LSTM）替代简单的线性疲劳公式，捕捉更复杂的非线性疲劳演化规律[4]；（b）扩大用户测试规模，收集更多个体数据以验证三阶段自适应模型的泛化能力；（c）探索多模态融合（sEMG + 加速度计 + 心率）以提升疲劳判断的准确性[5]。 ||||
