## 1. 项目背景与意义
肌肉疲劳的实时监测在运动科学、康复医学和人机交互中具有重要意义。表面肌电信号（sEMG）是一种通过皮肤表面电极采集肌肉电活动的非侵入式技术，已广泛应用于肌肉状态评估。
传统 sEMG 疲劳检测设备通常依赖昂贵的专用仪器和计算机端软件，不便携且成本高。本项目基于 Arduino UNO R4 WiFi 开发了一款便携式 sEMG 疲劳监测设备，具有以下特点：
- **低成本**：BOM 成本约 200 元人民币（sEMG 单通道干电极肌电传感器 + UNO R4 WiFi）
- **便携**：腕带式设计，可实时在手机微信小程序上查看数据
- **云端**：数据通过 WiFi 上传至微信云开发平台，支持历史分析
- **自主算法**：固件端实现完整的 RMS、MDF、激活度、疲劳度计算，无需计算机端处理

## 2. 算法整体架构
算法运行在 Arduino UNO R4 WiFi（瑞萨 RA4M1 芯片，主频 48MHz，RAM 32KB）上，采用定时器中断驱动采样，在主循环中完成全部信号处理。
**处理流程（8 步）**
| 步骤   | 处理内容                 | 输出               |
| ------ | ------------------------ | ------------------ |
| 1      | ADC 中断采样（1000Hz）   | 原始 sEMG 电压信号 |
| 2      | 环形缓冲区管理（512 点） | 滑动数据窗口       |
| 3      | RMS 计算（256 点窗口）   | 肌肉激活强度（mV） |
| 4      | FFT + 功率谱（256 点）   | 频谱分布           |
| 5      | MDF 计算（中值频率）     | 频谱中心位置（Hz） |
| 6      | 激活度归一化             | 0～100%            |
| 7      | 疲劳度计算（MDF 下降率） | 0～100%            |
| 8      | 信号质量评估             | 0～100 分          |

**关键设计决策**：由于 RA4M1 的 RAM 仅 32KB，FFT 使用 256 点（而非 512 点），以减少内存占用。频谱计算采用自实现定点 FFT（库仑复数旋转因子预计算），避免依赖大型 FFT 库。

## 3. 核心算法详解
### 3.1 信号采集与预处理
sEMG 干电极肌电传感器输出 0~3.0V 模拟信号，直接接入 UNO R4 WiFi 的 14 位 ADC（量程 0～3.3V）。采样由硬件定时器中断驱动，固定 **1000Hz**：
```cpp
// main.cpp — ADC 定时器配置
ADC::adc_timer.begin([]() {
  int16_t adcVal = analogRead(ADC_PIN);
  gSignalProcessor.pushSample(adcVal);
}, 1000.0f);  // 1000 Hz
```
**环形缓冲区设计**：使用 512 点的环形缓冲区（`RING_BUFFER_SIZE = 512`），写指针由中断上下文更新，读指针由主循环更新。采用 `volatile` 变量保护，避免中断与主循环之间的数据竞争。
**DC 偏移去除**：sEMG 信号含有电极与皮肤接触产生的 DC 偏移，计算 RMS 前需去除。采用窗口内简单均值法（而非去极值均值），因为 256 点已足够稳定，且去极值会破坏时序：
$$
DC_{bias} = \frac{1}{N} \sum_{i=0}^{N-1} x[i]
$$
其中 N = 256（FFT 窗口大小），x[i] 为 ADC 原始采样值（单位：mV）。
### 3.2 RMS（均方根）计算
RMS 反映肌肉收缩时的信号总功率，与收缩强度正相关，是激活度归一化的基础。
$$
RMS = \sqrt{\frac{1}{N} \sum_{i=0}^{N-1} (x[i] - DC_{bias})^2}
$$
- N = 256，对应 256 ms 时间窗口（@1000Hz 采样）
- x[i] 为经 50/60Hz 数字陷波（§3.7）去除工频干扰、再去除 DC 偏移后的交流分量（单位：mV）
- RMS 计算使用加窗**前**的原始信号，因为 RMS 反映时域能量，加窗会影响幅值准确性
- **工频抑制前提**：所有时域/频域计算均基于陷波后的干净信号，RMS 反映去除 50Hz 工频干扰后的真实肌电能量，而非被工频污染的幅值
### 3.3 MDF（中值频率）计算
MDF（Median Frequency，中值频率）是肌电信号频谱的中心位置，肌肉疲劳时 MDF 会系统性下降。这是本算法的核心疲劳指标，大量文献已验证其可靠性。
**FFT 实现**：使用 256 点实数 FFT（自实现，旋转因子预计算），加 Hamming 窗减少频谱泄露：
```
w[i] = 0.5 × (1 - cos(2πi / (N-1)))  // Hamming 窗
x_windowed[i] = (x[i] - DC_bias) × w[i]
```
> **工频抑制前提**：FFT 输入 x[i] 已先经过 50/60Hz 数字陷波（§3.7），50Hz 工频峰不再主导功率谱。因此 MDF 在弱信号（佩戴静息、未佩戴）下反映真实肌电频谱，而非被锁定在 ~50Hz 工频带（早期版本的典型故障：开路与佩戴静息的 MDF 都≈50Hz 而无法区分）。

**MDF 定义**：MDF 是使下式成立的频率 f_mdf：
$$
\int_{f_{min}}^{f_{mdf}} P(f) df = \int_{f_{mdf}}^{f_{max}} P(f) df = \frac{1}{2} \int_{f_{min}}^{f_{max}} P(f) df
$$
- P(f) 为功率谱密度
- f_min = 20 Hz，f_max = 250 Hz（传感器有效频谱 20~500Hz，受 FFT 分辨率限制上界取 250Hz）

**MDF 计算步骤**：
1. 计算功率谱：P[k] = (Re[k]² + Im[k]²) / N，k = 0 ～ N/2-1
2. 计算总功率：P_total = Σ P[k]（k 对应 20～250 Hz）
3. 若 P_total < 10⁻¹²，视为信号太弱，返回 -1（跳过本次）
4. 累积功率，找到使累积功率 ≥ 0.5 × P_total 的 bin
5. 线性插值获得精确 MDF 值

**EMA 平滑**：原始 MDF 值逐帧波动较大，采用指数移动平均（EMA）平滑：
$$
MDF_{current} = MDF_{last} \times (1 - \alpha) + MDF_{raw} \times \alpha
$$
| 信号状态           | α 值              | 设计理由                     |
| ------------------ | ----------------- | ---------------------------- |
| 收缩期 / MDF 下降  | 0.35              | 快速跟踪频谱变化，避免滞后   |
| 稳态期（>10 帧）   | 0.15              | 抑制逐帧抖动，输出平滑       |
| 启动过渡（<10 帧） | 0.5→0.15 线性过渡 | 避免初始值偏差导致长时间收敛 |
### 3.4 激活度（Activation）计算
激活度将实时 RMS 归一化到 0～100%，直观反映肌肉收缩强度。
$$
A(\%) = \text{clamp}\left( \frac{RMS_{current} - RMS_{relax}}{RMS_{active} - RMS_{relax}} \times 100\%,  0, 100 \right)
$$
- RMS_relax：校准得到的放松状态 RMS（10 秒静息均值）
- RMS_active：校准得到的主动收缩 RMS（15 秒最大收缩峰值）
- **物理意义**：A = 0% 表示完全放松，A = 100% 表示达到了校准时的最大收缩强度。
### 3.5 疲劳度（Fatigue）计算
疲劳度是本算法的核心输出，基于 MDF 下降幅度计算，归一化到 0～100%。
**公式（锚点公式 + 力交叉验证）**：
$$
F_{raw}(\%) = \begin{cases} 
\text{clamp}\left( \frac{MDF_{active} - MDF_{current}}{MDF_{active} - MDF_{end}} \times 100\%,  0, 100 \right) \times S_{force} & \text{收缩中} \\
F_{last} \times 0.998 & \text{放松时（指数恢复）}
\end{cases}
$$
其中力稳定性因子 $S_{force}$：
$$
S_{force} = 1 - \text{clamp}\left( \frac{|\frac{RMS}{RMS_{trend}} - 1| - 0.15}{0.35}, 0, 0.7 \right)
$$
- MDF_active：校准 Active 阶段记录的峰值 MDF（Hz），运行期间可在"新鲜态"（疲劳度<25%）下缓慢上抬自适应
- MDF_relax：校准 Relax 阶段记录的放松 MDF（Hz），作为疲劳 100% 锚点的下限兜底（floor = max(MDF_end, MDF_relax)）
- MDF_end：校准 Active 阶段**用力末（约第 12~15 秒）真实疲劳态**记录的 MDF（Hz），作为疲劳 100% 锚点。肌肉收缩到该状态即记为 100% 疲劳
- MDF_current：当前实时 MDF（Hz）
- **收缩门控（去抖）**：采用去抖后的收缩确认态 m_contractConfident 驱动疲劳计算——需连续 2 帧判定为收缩才进入，需连续 5 帧非收缩才退出，避免边界帧与放松瞬态 MDF 噪声误算疲劳。仅在确认收缩时按 MDF 计算疲劳；非收缩时冻结疲劳并按指数衰减恢复（半衰期 ~35s，基于 Elfving 2002）
- **双阈值收缩检测**：RMS > relax_rms × 2（相对阈值）且 RMS > max(active_rms × 0.3, 10mV)（动态绝对阈值，自动适应用户个体差异），移除 MDF 条件以避免极度疲劳时收缩检测失效（天花板效应）；该原始判定经上述去抖后形成 m_contractConfident
- **力稳定性交叉验证**：通过 RMS 慢速 EMA（τ≈3.3s）跟踪收缩力趋势，当 RMS 偏离趋势 >15% 时降低疲劳度置信度（最低至 30%），缓解 MDF 随力变化的混杂效应（Phinyomark 2012）

**EMA 平滑**：疲劳度变化是缓慢的生理过程（10～60 秒时间尺度），收缩时使用 α = 0.3 的 EMA 平滑（Phinyomark 2012 推荐 0.2-0.4 平衡响应速度与稳定性）：
$$
F_{smoothed}(t) = F_{smoothed}(t-1) \times 0.7 + \max(F_{raw}(t),\ 0) \times 0.3
$$
放松时采用指数衰减恢复：$F(t) = F(t-1) \times 0.998$，对应半衰期 ~35s（Elfving 2002）。

**锚点自适应（取代旧版"前30秒动态锚点"）**：旧版在运行前 30 秒自动抬升 activeMDF 已被取代。现采用三层设计：
- **疲劳 100% 锚点 = MDF_end（用力末真实疲劳 MDF）**：校准时已采集用力末 MDF 作为"真正疲劳到顶"的基准，分母 = (MDF_active − MDF_end)，疲劳度不再被钳位到 0，且更贴近个人真实疲劳极限
- **Phase 1 静息基线自校正**：非收缩且 RMS 稳定（偏离趋势 <15%）持续约 5 秒后，极慢 EMA（α=0.02）更新 relax_rms / relax_mdf，约束在 calib 参考 0.6~1.4 倍，缓慢适配个体差异
- **Phase 2 最大用力锚点修正**：在"新鲜态"（疲劳度 < 25%）下，若实时 MDF / RMS 超过校准峰值，缓慢上抬 activeMDF / activeRMS（钳位约束），适配用户校准时未达最大收缩的情况
- **Phase 3 云端纵向画像回灌**：设备启动会话时通过 getProfile 云函数拉取该用户最近一次校准（避免被历史脏数据覆盖），写回 EEPROM 即时生效，使设备"越用越个人化"

**锚点公式设计亮点**：传统方法使用校准时的 MDF_relax 作为固定基线，但存在基线捕获时机过早、且未反映真实疲劳极限的问题。本算法采用「峰值 + 用力末双锚点法」：
- 使用校准阶段记录的 Active 峰值 MDF 与用力末 MDF（MDF_end）作为分母两端锚点，分子为 (activeMDF - currentMDF)
- MDF_end 是校准用力末（约第 12~15 秒）真实疲劳态的 MDF，使 100% 对应"个人真实疲劳到顶"，而非主观"最大收缩"
- 收缩门控（去抖）+ 指数恢复确保放松时疲劳度按生理学规律恢复，避免非收缩状态下的误判
- 力稳定性交叉验证缓解 MDF 随力变化的混杂效应
- 该设计消除了基线捕获时机的不确定性，并使疲劳度更个人化、更贴近真实极限

### 3.5.1 校准协议要点（时长与接触压力）
- **时长设定依据**：Relax 阶段 10 秒取窗口内 RMS 均值（约 100 帧 @10Hz），均值稳定，8~10 秒即可，无需更长；Active 阶段 15 秒既用于捕捉早期 RMS 峰值（MVC 峰值），又必须持续到肌肉发展出真实疲劳态以记录 MDF_end（用力末 MDF，疲劳公式 100% 锚点），故 15 秒为必要时长，不宜缩至 3~5 秒。
- **接触压力伪迹（关键）**：RMS = 肌肉电活动 + 电极接触压力成分。若校准用力阶段手部接触状态（握姿、握持压力）与真实使用不一致，接触压力差会混入 (active − relax) 锚点，导致激活度失真（校准过猛→日常被判静息；校准过松→轻微用力即饱和）。**正确做法：校准两阶段保持同一手势，且用力阶段直接采用真实使用场景的手部状态与力度（例如平时握某物体就握着它、用真实劲），让接触压力成为共模在 (active − relax) 相减中抵消**。

### 3.6 信号质量评估
信号质量（0～100 分）实时反映当前 sEMG 信号是否可信，用于用户界面提示用户调整电极位置。
**评分规则**：
- **RMS 得分**（35 分）：收缩期 RMS 在 0.1～5 mV 为高质量；放松期 RMS < 0.5 mV 为高质量
- **MDF 有效性**（35 分）：MDF 在 [20, 250] Hz 范围内得满分
- **连续性**（30 分）：MDF 有效性的 EMA 平滑比例（α=0.05，约2秒时间常数）× 30，避免周期性跳变
- **电极开路/未佩戴硬判定**：当 §3.7 的工频能量检测（50+60Hz 合并）判定为开路时，信号质量直接置为 3 分（最低），同时冻结疲劳度与激活度输出（见 §3.7），避免开路噪声被误算为疲劳或误报高收缩

### 3.7 工频抑制与电极开路（未佩戴）检测
干电极接触阻抗高时，前端放大器共模抑制比（CMRR）下降，环境 50Hz 工频干扰易耦合进信号；电极完全开路（悬空）时该干扰极强。若不做处理，50Hz 峰会主导功率谱，使 MDF 被锁定在 ~50Hz，并让 RMS 暴涨，系统无法区分"开路"与"真实高收缩"。

**1）50/60Hz 数字陷波**
在 ADC 采样入口（`pushSample`）对每一样本级联两级二阶 IIR 陷波滤波器：
- 50Hz 陷波：中心频率 50Hz，Q = 25（−3dB 带宽 ≈ 2Hz），用于抑制市电工频
- 60Hz 陷波：中心频率 60Hz，Q = 25，用于抑制部分地区/设备的 60Hz 干扰
- 采用 RBJ 双二阶（biquad）标准陷波结构，极点略在单位圆内以保证数值稳定
- 陷波后的干净信号存入环形缓冲，供 RMS / MDF / 疲劳度全部下游计算使用

陷波器从原始信号中移除的工频分量 `diff = raw - notched` 被单独累计，用于下方的开路检测。

**2）基于工频能量的开路（未佩戴）检测（取代旧 MDF 判据）**
旧版用"MDF 中位数 ∈ [40, 60] Hz 且 RMS > 30 mV"判开路，但弱信号下 MDF 已被 50Hz 污染而恒≈50Hz，导致**佩戴时小幅动作（RMS 瞬间 > 30）即误报"未佩戴"**。现改为**直接度量被陷波移除的 50+60Hz 工频总能量**：

$$
P_{mains} = \mathrm{EMA}\big((raw - notched)^2\big), \qquad RMS_{mains} = \sqrt{P_{mains}}
$$

- 开路（电极悬空）：50/60Hz 共模干扰极强，$RMS_{mains}$ ≈ 800–1340 mV（实测）
- 佩戴（强 50Hz 环境下人体/放大器 CMRR 抑制有限）：工频能量仍可达 $RMS_{mains}$ ≈ 130–600 mV（实测）
- 两者实测区间存在约 600–800 mV 的干净间隙，用**双阈值滞回**区分，且**不再依赖被污染的 MDF**

**判定逻辑（双阈值滞回）**：
- 进入开路：$RMS_{mains} > 700\,\mathrm{mV}$（`MAINS_OPEN_ENTER_MV`），连续 3 帧确认（防单帧尖峰误触发）
- 退出开路：$RMS_{mains} < 400\,\mathrm{mV}$（`MAINS_OPEN_EXIT_MV`），连续 5 帧（~500ms）确认才清除（防重新佩戴瞬态抖动）
- 中间带（400–700 mV）维持原状态，避免临界区抖动；阈值依据实测：佩戴上界≈600mV、真开路下界≈800mV，留足裕度

**开路时输出冻结**：检测到开路（未佩戴）时，信号质量直接置为 3 分（最低），前端据此显示“请佩戴”横幅；疲劳度冻结为上次有效值（不清零、不更新），激活度清零并直接返回——**不再输出虚假 100%**。小程序端（`pages/realtime`）以 `quality < 30` 反推未佩戴状态，将疲劳度与激活度统一显示为 `--`。此外，当设备**未校准**（固件 `m_isCalibrated == false`，例如在小程序删除校准数据后固件 EEPROM 被清空）时，固件在每帧数据点中置 `calibrated = 0`，云端据其同样将激活度与疲劳度显示为 `--`，仅保留 RMS / MDF 原始信号——与"未佩戴"同口径，避免无基准时输出无意义数值。

### 3.8 设备"越用越适合个人"：个性化闭环（核心亮点）

本设备的算法**不是一套写死在固件里的固定公式**，而是一个**会持续自适应并长期记忆当前用户生理特征的个性化系统**（注：此处的"学习 / 自适应"指参数在线更新，并非机器学习训练）。用户在每一次佩戴、校准、使用的过程中，都在"教"设备认识自己的身体；设备把这些个性化特征沉淀到本地 EEPROM 与云端画像，使下一次使用一开机就比上一次更贴合用户。这正是本项目区别于普通 sEMG 设备的最大亮点——**越用越适合个人**。

个性化由三个层次共同实现，覆盖"单次会话内"与"跨会话长期"两个时间尺度：

**(1) 会话内本地自适应（每次开机即时贴合）**
- **静息基线自校正（Phase 1）**：设备佩戴后、非收缩且信号稳定约 5 秒，便以极慢 EMA（α=0.02）自动学习该用户的放松态 RMS/MDF，并用校准参考的 0.6~1.4 倍做安全约束，缓慢适配个体差异。用户无需手动设定"什么是放松"。
- **最大用力锚点修正（Phase 2）**：在"新鲜态"（疲劳度 < 25%）下，若实时信号超过校准峰值，设备会缓慢上抬 activeMDF / activeRMS 锚点（钳位范围 0.8~1.5× 校准参考，activeMDF 另限 400Hz 上限），自动修正用户校准时"没使出全力"带来的低估，让疲劳度 100% 对应其真实极限。

**(2) 跨会话云端画像回灌（"越用越适合个人"的关键）**
- 设备每次完成一次规范校准，都会把 `relax_rms / relax_mdf / active_rms / active_mdf / end_mdf` 这组"用户生理画像"上传云端（`uploadCalibration` 云函数）。
- 下次开机时，固件通过 `getProfile` 云函数**拉取该用户最近一次**的高质量校准，直接回灌到 EEPROM 即时生效——相当于设备"记得"你上次的身体状况，无需重新调参、无需重新校准，即可以贴合你的状态启动。
- 这正是"越用越适合个人"的技术支点：每一次规范校准都在累积并刷新这份画像，**使用越久、校准越规范，设备对你的建模越准确**。

**(3) 数据卫生保障（让"记忆"保持干净）**
- 云端画像只采纳**最近一次 completed 校准**，且提供 `cleanSessions` 云函数清理历史脏数据（如误触产生的空 session、电极开路时误存的记录），避免脏历史把个性化锚点拉偏。
- 校准协议要求两阶段保持**同一真实手势**（§3.5.1），使电极接触压力成为共模在相减中抵消，保证每次写入画像的"力"是真实的肌肉力而非握持压力，进一步保障画像质量。

**闭环示意**：
```
用户佩戴/校准 → 本地 Phase1/2 自适应（本次即用） ┐
│                                                │  画像沉淀
└→ uploadCalibration → 云端用户画像 ─────────────┘
下次开机 → getProfile 回灌 EEPROM → 以更贴合的状态启动（越用越个人化）
              ↑ 脏数据由 cleanSessions 清理，保证记忆质量
```

**与普通固定算法设备的对比（答辩可用）**：
| 维度     | 固定算法设备                           | 本设备（越用越适合个人）           |
| -------- | -------------------------------------- | ---------------------------------- |
| 校准     | 每次都要重新标定，且参数对所有用户一致 | 校准画像云端记忆，下次开机自动继承 |
| 个体差异 | 靠用户手动选档 / 调阈值                | 静息基线与最大用力锚点自动学习     |

## 4. 创新亮点
本项目的算法设计有以下创新点，适合作为高中生科创项目的亮点展示：
### 亮点一：基于 MDF 的「峰值 + 用力末」双锚点公式疲劳检测
传统 sEMG 疲劳检测使用校准时的 MDF_relax 作为固定基线，存在基线捕获时机过早、且未反映真实疲劳极限的问题。本算法创新地采用「峰值 + 用力末双锚点法」：
- 使用校准阶段记录的 Active 峰值 MDF 与用力末 MDF（MDF_end）作为两个锚点
- 公式 $F = \frac{activeMDF - currentMDF}{activeMDF - endMDF} \times 100\%$，使 100% 对应"个人校准用力末的真实疲劳态"
- 收缩门控（去抖）+ 指数恢复模型（半衰期 ~35s，基于 Elfving 2002）确保放松时疲劳度按生理学规律恢复
- 力稳定性交叉验证缓解 MDF 随力变化的混杂效应（Phinyomark 2012）
- 该设计消除了动态基线捕获时机的不确定性，并使疲劳度更个人化、更贴近真实极限

### 亮点二：自适应 EMA 平滑参数 + 力交叉验证
MDF 的 EMA 平滑参数 α 不是固定值，而是根据信号状态自适应调整。此外，通过 RMS 慢速 EMA 跟踪收缩力趋势，当检测到力快速变化时自动降低疲劳度置信度（最低至 30%），缓解了文献中已知的 MDF-力混杂效应。这是一个体现「算法针对性设计」的亮点，适合在答辩中展示。
### 亮点三：极低资源的嵌入式实现
Arduino UNO R4 WiFi 仅有 32KB RAM 和 48MHz 主频，在这样的限制下实现实时 FFT + MDF 计算 + 力交叉验证是一个工程亮点：
- FFT 旋转因子预计算并存储在 BSS 段（`static` 数组），避免每次计算重新生成
- 使用 256 点 FFT（而非 512 点），在满足频率分辨率的同时控制 RAM 占用
- 环形缓冲区设计避免大数组的栈分配（RA4M1 主栈仅 1KB）
- 固件编译后 RAM 使用率约 **68%（随构建浮动）**，在严格限制下成功实现全部功能
### 亮点四：完整的本地 + 云端数据闭环
固件端完成全部算法计算，结果（RMS、MDF、激活度、疲劳度）通过 WiFi 每 3 秒上传至微信云开发平台，用户可在微信小程序上实时查看，并支持历史数据查询。

### 亮点五：越用越适合个人的"个性化闭环"（核心亮点）
前面四个亮点解决的是"算得准、跑得动、看得见"，而本亮点解决的是"设备是否认识你"——这是本项目最贴近用户感知、也最差异化的能力。

普通 sEMG 设备用的是一套对所有用户一致的固定参数，每次使用都要重新标定；本设备则把每位用户当成独立个体来建模：
- **会话内即时贴合**：静息基线自校正（Phase 1）与最大用力锚点修正（Phase 2）让设备在单次开机内就自动学习"你的放松态"和"你的最大极限"，无需手动选档。
- **跨会话长期记忆**：每次规范校准都会通过 `uploadCalibration` 把你的生理画像写入云端；下次开机 `getProfile` 直接回灌 EEPROM，设备"记得"你上次的状态，开箱即贴合（详见 §3.8）。
- **记忆可保鲜**：`cleanSessions` 清理脏历史，校准要求同手势以保证画像真实，避免"越用越歪"。

一句话概括：**设备不是用一次就忘的固定仪器，而是越用越懂你的长期伙伴**——使用越久、校准越规范，疲劳度与激活度越贴近你的真实身体，这是面向消费者与康复场景最有说服力的产品亮点。

### 5.3 方法学说明与适用范围

**锚点公式的学术定位**：
本算法的锚点归一化公式 $F = \frac{activeMDF - curMDF}{activeMDF - endMDF} \times 100\%$ 是基于 MDF 疲劳下降原理的**创新适配**（endMDF 为校准用力末真实疲劳态 MDF，使 100% 对应个人真实疲劳极限），而非直接引用某篇论文的标准方法。文献中常用的标准方法包括：
- MDF 斜率法：对 MDF-t 做线性回归，斜率为负表示疲劳（Merletti 1990; Cifrek 2009）
- MDF 归一化比值：MDF(t) / MDF(初始值)，观察比值随时间下降（González-Izal 2012）
- 本算法采用双锚点归一化是针对嵌入式实时场景的工程适配，消除了动态基线捕获时机的不确定性

**MDF 线性下降的适用条件**：
文献确认"MDF decreases linearly over time"（Frontiers 2022），但该结论**主要基于等长收缩（isometric contraction）实验**。本算法在以下场景中的可靠性：
- 等长收缩（如握力保持）：可靠性高 ✅
- 低动态收缩（如缓慢反复抓握）：可靠性中等 ⚠️
- 高动态运动（如快速挥臂、跑步）：可靠性低，需时频分析方法 ⚠️

**力混杂效应的已知局限**：
MDF 不仅随疲劳变化，也随收缩力水平变化（Phinyomark 2012 综述了三种矛盾结论：CF1 无关 / CF2 正相关 / CF3 负相关）。本算法通过 RMS 趋势交叉验证缓解此问题，但无法完全消除。建议用户在监测期间**保持稳定的收缩力度**以获得准确的疲劳度读数。

**放松恢复模型的依据**：
放松时采用指数衰减恢复（半衰期 ~35s），基于 Elfving et al. (2002) 对 55 名受试者的 MDF 恢复研究（r²=0.98）。该模型比纯 Hold（永不恢复，高估疲劳）和快速衰减（3s 归零，丢失疲劳状态）更符合生理学。

**单特征局限与多特征趋势**：
本算法仅使用 MDF 单一频域特征。最新研究趋势是多特征融合（如 Miaoulis et al. 2025 使用 8 特征 + PCA + RF，R²=0.52）。受 RA4M1 算力限制，本算法通过 RMS 趋势交叉验证作为轻量化的双特征互补方案。

## 附录：核心公式汇总
| 符号       | 公式                                                                                                                                                    | 说明                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| RMS        | $\sqrt{\frac{1}{N}\sum_{i=0}^{N-1}(x[i]-DC_{bias})^2}$                                                                                                  | 肌肉激活强度（mV）                                                                          |
| MDF        | $\int_{f_{min}}^{MDF} P(f)\,df = \frac{1}{2}P_{total}$                                                                                                  | 频谱中心频率（Hz）                                                                          |
| 激活度 A   | $A = \mathrm{clamp}\!\left(\frac{RMS - RMS_r}{RMS_a - RMS_r}\times 100,\ 0,\ 100\right)$                                                                | 归一化收缩强度（%）                                                                         |
| 疲劳度 F   | $F = \mathrm{clamp}\!\left(\frac{MDF_a - MDF_{cur}}{MDF_a - MDF_{end}}\times 100,\ 0,\ 100\right)\times S_{force}$（收缩中），$F\times 0.998$（放松时） | 基于 MDF 下降的疲劳指数（%），100% 锚点=用力末 MDF，收缩门控（去抖）+ 力交叉验证 + 指数恢复 |
| 疲劳度平滑 | $F(t) = F(t-1)\times 0.7 + \max(F_{raw}(t),\ 0)\times 0.3$（收缩时），$F(t) = F(t-1)\times 0.998$（放松时）                                             | EMA 平滑（α=0.3）+ 指数恢复（half-life≈35s），f_raw≥0 避免负值                              |
| 力稳定性   | $S_{force} = 1 - \mathrm{clamp}\!\left(\frac{\lvert \frac{RMS}{RMS_{trend}}-1\rvert - 0.15}{0.35},\ 0,\ 0.7\right)$                                     | 力变化时降低疲劳置信度                                                                      |

注：RMS_r = 放松状态 RMS，RMS_a = 主动收缩 RMS，MDF_r = 放松 MDF，MDF_a = Active 峰值 MDF，MDF_end = Active 用力末（真实疲劳态）MDF，N = 256，RMS_trend = RMS 慢速 EMA（α=0.03）。
