# cnki_gui —— 知网文献检索 Skill（直接驱动 Edge，单文件）

## 触发词
知网检索 / 搜知网 / 知网文献搜索 / 找知网论文 / 知网关键词搜索

## 设计说明（重要）
**本 skill 没有本地网页 / 没有本地服务端口**，因此也不会出现"点搜索没反应""关页面后冒出多个 Edge"等问题。
双击后只做两件事：
1. 用固定账号 `qbzxyx30` 确保 Edge 已登录知网（已登录则直接复用会话，秒过）；
2. 直接把 Edge 打开到**知网检索入口页** `https://kns.cnki.net/kns8s/`。

之后**关键词在 Edge 里自己输入**，看结果、点链接下载，全部在知网原生页面完成。
（原本的"本地 GUI 列文献卡片"方案因前端 fetch / 多窗口错乱被废弃，改为让用户在 Edge 里直接操作。）

> 为什么这样更简单可靠：知网结果页本身就是带搜索框、作者、来源、下载按钮的完整界面，
> 没必要再自己抓一遍再画一个网页；少一层本地服务，就少一层出 bug 的可能。

## 使用方式（双击即用）
1. 双击 `cnki_gui.pyw`：自动登录（若需要）并打开 Edge 到知网检索页。
2. 在 Edge 顶部的知网搜索框输入关键词（如 `弯举 肌电 疲劳`），回车检索。
3. 结果页里直接看文献、点「下载」链接自行完成滑块验证并下载 PDF。

命令行用法：
- `python cnki_gui.pyw --search "弯举 肌电 疲劳"`  → 直接打开该关键词的检索结果页（不起服务、不开本地页面）
- 不带参数双击 = 打开空白检索入口页，关键词在 Edge 里输入。

## 组件
| 文件 | 说明 |
| --- | --- |
| `cnki_gui.pyw` | **唯一程序文件**：`ensure_login()` 登录检查 + `open_search_page()` 打开知网检索页；无 HTTP 服务 |

## 依赖
- xbrowser 已初始化（`xb init` 返回 ready），且配置了 Edge（`config.json` 中 `"browser":"edge"`）。
- node 运行时：脚本自动探测 WorkBuddy 自带 node，或 `shutil.which("node")`，或 QClaw 内置 node。
- 账号固定 `qbzxyx30 / 11223373`（项目共用，不可改动）。

## 注意事项
- 登录态会在 `x.cnki.net` 与 `kns.cnki.net` 之间共享（同一知网账号 cookie），所以登录一次后检索页也是已登录状态。
- 若双击后 Edge 没自动跳到检索页，多半是 xbrowser/Edge 调试会话未就绪，关闭多余 Edge 后重双击一次即可。
- 连续快速双击会被单实例锁拦掉（避免开出多个 Edge），等几秒再双击。
- 文献下载受知网权限/积分限制，部分文献可能仅能在线阅读；下载全文的滑块验证需用户手动拖一下。
