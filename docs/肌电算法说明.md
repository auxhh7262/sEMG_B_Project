## 1. 项目背景与意义
肌肉疲劳的实时监测在运动科学、康复医学和人机交互中具有重要意义。表面肌电信号（sEMG）是一种通过皮肤表面电极采集肌肉电活动的非侵入式技术，已广泛应用于肌肉状态评估。
传统 sEMG 疲劳检测设备通常依赖昂贵的专用仪器和计算机端软件，不便携且成本高。本项目基于 Arduino UNO R4 WiFi 开发了一款便携式 sEMG 疲劳监测设备，具有以下特点：
- **低成本**：BOM 成本约 200 元人民币（sEMG 单通道干电极肌电传感器 + UNO R4 WiFi）
- **便携**：腕带式设计，可实时在手机微信小程序上查看数据
- **云端**：数据通过 WiFi 上传至微信云开发平台，支持历史分析
- **自主算法**：固件端实现完整的 RMS、MDF、激活度、疲劳度计算，无需计算机端处理

## 2. 算法整体架构
算法运行在 Arduino UNO R4 WiFi（瑞萨 RA4M1 芯片，主频 48MHz，RAM 32KB）上，采用定时器中断驱动采样，在主循环中完成全部信号处理。
**处理流程（8 步）**
| 步骤 | 处理内容 | 输出 |
|------|---------|------|
| 1 | ADC 中断采样（1000Hz） | 原始 sEMG 电压信号 |
| 2 | 环形缓冲区管理（512 点） | 滑动数据窗口 |
| 3 | RMS 计算（256 点窗口） | 肌肉激活强度（mV） |
| 4 | FFT + 功率谱（256 点） | 频谱分布 |
| 5 | MDF 计算（中值频率） | 频谱中心位置（Hz） |
| 6 | 激活度归一化 | 0～100% |
| 7 | 疲劳度计算（MDF 下降率） | 0～100% |
| 8 | 信号质量评估 | 0～100 分 |

**关键设计决策**：由于 RA4M1 的 RAM 仅 32KB，FFT 使用 256 点（而非 512 点），以减少内存占用。频谱计算采用自实现定点 FFT（库仑复数旋转因子预计算），避免依赖大型 FFT 库。

## 3. 核心算法详解
### 3.1 信号采集与预处理
sEMG 干电极肌电传感器输出 0~3.0V 模拟信号，直接接入 UNO R4 WiFi 的 14 位 ADC（量程 0～3.3V）。采样由硬件定时器中断驱动，固定 **1000Hz**：
```cpp
// main.cpp — ADC 定时器配置
ADC::adc_timer.begin([]() {
  int16_t adcVal = analogRead(ADC_PIN);
  gSignalProcessor.pushSample(adcVal);
}, 1000.0f);  // 1000 Hz
```
**环形缓冲区设计**：使用 512 点的环形缓冲区（`RING_BUFFER_SIZE = 512`），写指针由中断上下文更新，读指针由主循环更新。采用 `volatile` 变量保护，避免中断与主循环之间的数据竞争。
**DC 偏移去除**：sEMG 信号含有电极与皮肤接触产生的 DC 偏移，计算 RMS 前需去除。采用窗口内简单均值法（而非去极值均值），因为 256 点已足够稳定，且去极值会破坏时序：
$$
DC_{bias} = \frac{1}{N} \sum_{i=0}^{N-1} x[i]
$$
其中 N = 256（FFT 窗口大小），x[i] 为 ADC 原始采样值（单位：mV）。
### 3.2 RMS（均方根）计算
RMS 反映肌肉收缩时的信号总功率，与收缩强度正相关，是激活度归一化的基础。
$$
RMS = \sqrt{\frac{1}{N} \sum_{i=0}^{N-1} (x[i] - DC_{bias})^2}
$$
- N = 256，对应 256 ms 时间窗口（@1000Hz 采样）
- x[i] 为经 50/60Hz 数字陷波（§3.7）去除工频干扰、再去除 DC 偏移后的交流分量（单位：mV）
- RMS 计算使用加窗**前**的原始信号，因为 RMS 反映时域能量，加窗会影响幅值准确性
- **工频抑制前提**：所有时域/频域计算均基于陷波后的干净信号，RMS 反映去除 50Hz 工频干扰后的真实肌电能量，而非被工频污染的幅值
### 3.3 MDF（中值频率）计算
MDF（Median Frequency，中值频率）是肌电信号频谱的中心位置，肌肉疲劳时 MDF 会系统性下降。这是本算法的核心疲劳指标，大量文献已验证其可靠性。
**FFT 实现**：使用 256 点实数 FFT（自实现，旋转因子预计算），加 Hamming 窗减少频谱泄露：
```
w[i] = 0.5 × (1 - cos(2πi / (N-1)))  // Hamming 窗
x_windowed[i] = (x[i] - DC_bias) × w[i]
```
> **工频抑制前提**：FFT 输入 x[i] 已先经过 50/60Hz 数字陷波（§3.7），50Hz 工频峰不再主导功率谱。因此 MDF 在弱信号（佩戴静息、未佩戴）下反映真实肌电频谱，而非被锁定在 ~50Hz 工频带（早期版本的典型故障：开路与佩戴静息的 MDF 都≈50Hz 而无法区分）。

**MDF 定义**：MDF 是使下式成立的频率 f_mdf：
$$
\int_{f_{min}}^{f_{mdf}} P(f) df = \int_{f_{mdf}}^{f_{max}} P(f) df = \frac{1}{2} \int_{f_{min}}^{f_{max}} P(f) df
$$
- P(f) 为功率谱密度
- f_min = 20 Hz，f_max = 250 Hz（传感器有效频谱 20~500Hz，受 FFT 分辨率限制上界取 250Hz）

**MDF 计算步骤**：
1. 计算功率谱：P[k] = (Re[k]² + Im[k]²) / N，k = 0 ～ N/2-1
2. 计算总功率：P_total = Σ P[k]（k 对应 20～250 Hz）
3. 若 P_total < 10⁻¹²，视为信号太弱，返回 -1（跳过本次）
4. 累积功率，找到使累积功率 ≥ 0.5 × P_total 的 bin
5. 线性插值获得精确 MDF 值

**EMA 平滑**：原始 MDF 值逐帧波动较大，采用指数移动平均（EMA）平滑：
$$
MDF_{current} = MDF_{last} \times (1 - \alpha) + MDF_{raw} \times \alpha
$$
| 信号状态 | α 值 | 设计理由 |
|---------|----------|---------|
| 收缩期 / MDF 下降 | 0.35 | 快速跟踪频谱变化，避免滞后 |
| 稳态期（>10 帧） | 0.15 | 抑制逐帧抖动，输出平滑 |
| 启动过渡（<10 帧） | 0.5→0.15 线性过渡 | 避免初始值偏差导致长时间收敛 |
### 3.4 激活度（Activation）计算
激活度将实时 RMS 归一化到 0～100%，直观反映肌肉收缩强度。
$$
A(\%) = \text{clamp}\left( \frac{RMS_{current} - RMS_{relax}}{RMS_{active} - RMS_{relax}} \times 100\%,  0, 100 \right)
$$
- RMS_relax：校准得到的放松状态 RMS（10 秒静息均值）
- RMS_active：校准得到的主动收缩 RMS（15 秒最大收缩峰值）
- **物理意义**：A = 0% 表示完全放松，A = 100% 表示达到了校准时的最大收缩强度。
### 3.5 疲劳度（Fatigue）计算
疲劳度是本算法的核心输出，基于 MDF 下降幅度计算，归一化到 0～100%。
**公式（锚点公式 + 力交叉验证）**：
$$
F_{raw}(\%) = \begin{cases} 
\text{clamp}\left( \frac{MDF_{active} - MDF_{current}}{MDF_{active} - MDF_{relax}} \times 100\%,  0, 100 \right) \times S_{force} & \text{收缩中} \\
F_{last} \times 0.998 & \text{放松时（指数恢复）}
\end{cases}
$$
其中力稳定性因子 $S_{force}$：
$$
S_{force} = 1 - \text{clamp}\left( \frac{|\frac{RMS}{RMS_{trend}} - 1| - 0.15}{0.35}, 0, 0.7 \right)
$$
- MDF_active：校准 Active 阶段记录的峰值 MDF（Hz），运行期间可动态更新
- MDF_relax：校准 Relax 阶段记录的放松 MDF（Hz）
- MDF_current：当前实时 MDF（Hz）
- **收缩门控**：仅在肌肉收缩时计算疲劳度，放松时疲劳度按指数衰减恢复（半衰期 ~35s，基于 Elfving 2002 的 MDF 恢复模型），避免纯 Hold（永不恢复）和快速衰减（3s 归零丢失疲劳状态）两种极端
- **双阈值收缩检测**：RMS > relax_rms × 2（相对阈值）且 RMS > max(active_rms × 0.3, 10mV)（动态绝对阈值，自动适应用户个体差异），移除 MDF 条件以避免极度疲劳时收缩检测失效（天花板效应）
- **力稳定性交叉验证**：通过 RMS 慢速 EMA（τ≈3.3s）跟踪收缩力趋势，当 RMS 偏离趋势 >15% 时降低疲劳度置信度（最低至 30%），缓解 MDF 随力变化的混杂效应（Phinyomark 2012）

**EMA 平滑**：疲劳度变化是缓慢的生理过程（10～60 秒时间尺度），收缩时使用 α = 0.3 的 EMA 平滑（Phinyomark 2012 推荐 0.2-0.4 平衡响应速度与稳定性）：
$$
F_{smoothed}(t) = F_{smoothed}(t-1) \times 0.7 + \max(F_{raw}(t),\ 0) \times 0.3
$$
放松时采用指数衰减恢复：$F(t) = F(t-1) \times 0.998$，对应半衰期 ~35s（Elfving 2002）。

**动态锚点更新**：运行期间前30秒如果检测到 MDF 持续超过校准峰值（用户校准时未达到最大收缩），自动更新 activeMDF 锚点，避免疲劳度被钳位到 0。30秒后冻结锚点，防止会话中漂移。

**锚点公式设计亮点**：传统方法使用校准时的 MDF_relax 作为固定基线，但存在基线捕获时机过早的问题。本算法采用「峰值锚点法」：
- 使用校准阶段记录的 Active 峰值 MDF 和 Relax MDF 作为两个锚点
- 公式分母为 (activeMDF - relaxMDF)，表示 MDF 可能的变化范围
- 公式分子为 (activeMDF - currentMDF)，表示当前 MDF 相对于峰值的下降量
- 收缩门控 + 指数恢复确保放松时疲劳度按生理学规律恢复，避免非收缩状态下的误判
- 力稳定性交叉验证缓解 MDF 随力变化的混杂效应
- 该设计消除了动态基线捕获时机的不确定性，提高了算法稳定性和一致性
### 3.6 信号质量评估
信号质量（0～100 分）实时反映当前 sEMG 信号是否可信，用于用户界面提示用户调整电极位置。
**评分规则**：
- **RMS 得分**（35 分）：收缩期 RMS 在 0.1～5 mV 为高质量；放松期 RMS < 0.5 mV 为高质量
- **MDF 有效性**（35 分）：MDF 在 [20, 250] Hz 范围内得满分
- **连续性**（30 分）：MDF 有效性的 EMA 平滑比例（α=0.05，约2秒时间常数）× 30，避免周期性跳变
- **电极开路/未佩戴硬判定**：当 §3.7 的工频能量检测（50+60Hz 合并）判定为开路时，信号质量直接置为 3 分（最低），同时冻结疲劳度与激活度输出（见 §3.7），避免开路噪声被误算为疲劳或误报高收缩

### 3.7 工频抑制与电极开路（未佩戴）检测
干电极接触阻抗高时，前端放大器共模抑制比（CMRR）下降，环境 50Hz 工频干扰易耦合进信号；电极完全开路（悬空）时该干扰极强。若不做处理，50Hz 峰会主导功率谱，使 MDF 被锁定在 ~50Hz，并让 RMS 暴涨，系统无法区分"开路"与"真实高收缩"。

**1）50/60Hz 数字陷波**
在 ADC 采样入口（`pushSample`）对每一样本级联两级二阶 IIR 陷波滤波器：
- 50Hz 陷波：中心频率 50Hz，Q = 25（−3dB 带宽 ≈ 2Hz），用于抑制市电工频
- 60Hz 陷波：中心频率 60Hz，Q = 25，用于抑制部分地区/设备的 60Hz 干扰
- 采用 RBJ 双二阶（biquad）标准陷波结构，极点略在单位圆内以保证数值稳定
- 陷波后的干净信号存入环形缓冲，供 RMS / MDF / 疲劳度全部下游计算使用

陷波器从原始信号中移除的工频分量 `diff = raw - notched` 被单独累计，用于下方的开路检测。

**2）基于工频能量的开路（未佩戴）检测（取代旧 MDF 判据）**
旧版用"MDF 中位数 ∈ [40, 60] Hz 且 RMS > 30 mV"判开路，但弱信号下 MDF 已被 50Hz 污染而恒≈50Hz，导致**佩戴时小幅动作（RMS 瞬间 > 30）即误报"未佩戴"**。现改为**直接度量被陷波移除的 50+60Hz 工频总能量**：

$$
P_{mains} = \mathrm{EMA}\big((raw - notched)^2\big), \qquad RMS_{mains} = \sqrt{P_{mains}}
$$

- 开路（电极悬空）：50/60Hz 共模干扰极强，$RMS_{mains}$ ≈ 500–1500 mV
- 佩戴（人体/放大器 CMRR 抑制）：工频能量极小，$RMS_{mains}$ ≈ 5–8 mV
- 两者相差约 100 倍，判别干净，且**不再依赖被污染的 MDF**

**判定逻辑（非对称滞回）**：
- 进入开路：$RMS_{mains} > 80\,\mathrm{mV}$，连续 3 帧确认（防单帧尖峰误触发）
- 退出开路：$RMS_{mains} \le 80\,\mathrm{mV}$，连续 5 帧（~500ms）确认才清除（防重新佩戴瞬态抖动）
- 阈值 `MAINS_OPEN_THRESHOLD_MV = 80.0f`（mV）：离开路 500mV 余量极大；同时消除重新佩戴过渡瞬态（≈20–40mV）造成的 2 行短暂“请佩戴”闪动

**开路时输出冻结**：检测到开路（未佩戴）时，信号质量直接置为 3 分（最低），前端据此显示“请佩戴”横幅；疲劳度冻结为上次有效值（不清零、不更新），激活度清零并直接返回——**不再输出虚假 100%**。小程序端（`pages/realtime`）以 `quality < 30` 反推未佩戴状态，将疲劳度与激活度统一显示为 `--`。

## 4. 创新亮点
本项目的算法设计有以下创新点，适合作为高中生科创项目的亮点展示：
### 亮点一：基于 MDF 的锚点公式疲劳检测
传统 sEMG 疲劳检测使用校准时的 MDF_relax 作为固定基线，存在基线捕获时机过早的问题（刚收缩时 MDF 可能还在上升期）。本算法创新地采用「峰值锚点法」：
- 使用校准阶段记录的 Active 峰值 MDF 和 Relax MDF 作为两个锚点
- 公式 F = (activeMDF - currentMDF) / (activeMDF - relaxMDF) × 100%
- 收缩门控 + 指数恢复模型（半衰期 ~35s，基于 Elfving 2002）确保放松时疲劳度按生理学规律恢复
- 力稳定性交叉验证缓解 MDF 随力变化的混杂效应（Phinyomark 2012）
- 该设计消除了动态基线捕获时机的不确定性，提高了算法稳定性和一致性

### 亮点二：自适应 EMA 平滑参数 + 力交叉验证
MDF 的 EMA 平滑参数 α 不是固定值，而是根据信号状态自适应调整。此外，通过 RMS 慢速 EMA 跟踪收缩力趋势，当检测到力快速变化时自动降低疲劳度置信度（最低至 30%），缓解了文献中已知的 MDF-力混杂效应。这是一个体现「算法针对性设计」的亮点，适合在答辩中展示。
### 亮点三：极低资源的嵌入式实现
Arduino UNO R4 WiFi 仅有 32KB RAM 和 48MHz 主频，在这样的限制下实现实时 FFT + MDF 计算 + 力交叉验证是一个工程亮点：
- FFT 旋转因子预计算并存储在 BSS 段（`static` 数组），避免每次计算重新生成
- 使用 256 点 FFT（而非 512 点），在满足频率分辨率的同时控制 RAM 占用
- 环形缓冲区设计避免大数组的栈分配（RA4M1 主栈仅 1KB）
- 固件编译后 RAM 使用率约 **68.2%**（约 22KB / 32KB），在严格限制下成功实现全部功能
### 亮点四：完整的本地 + 云端数据闭环
固件端完成全部算法计算，结果（RMS、MDF、激活度、疲劳度）通过 WiFi 每 3 秒上传至微信云开发平台，用户可在微信小程序上实时查看，并支持历史数据查询。

## 5. 优点与缺点分析
### 5.1 优点
| 优点 | 说明 | 学术/实用价值 |
|------|------|--------------|
| 实时性强 | 固件端 10Hz 计算频率，延迟 < 100ms | 适合运动中的实时反馈 |
| 低功耗便携 | 腕带式设计，USB 供电，可长时间监测 | 适合运动科学和康复场景 |
| MDF 锚点公式 | 使用校准阶段的峰值 MDF 和放松 MDF 作为锚点 | 消除基线捕获时机不确定性，提高稳定性 |
| 指数恢复模型 | 放松时疲劳度按半衰期 ~35s 指数恢复 | 符合 Elfving 2002 的 MDF 恢复生理学模型 |
| 力交叉验证 | RMS 趋势 EMA 检测力变化，动态降低置信度 | 缓解 MDF-力混杂效应（Phinyomark 2012） |
| 自适应 EMA | 根据信号状态调整平滑参数 | 兼顾响应速度和稳定性 |
| 信号质量指示 | 实时评估信号质量，提示用户调整电极 | 提高数据可靠性 |
| 成本极低 | BOM 约 200 元，远低于商用 sEMG 设备 | 适合教育推广 |
| 云端数据 | 微信小程序 + 云开发，无需安装 App | 用户友好，数据可回溯 |

### 5.2 缺点与局限性
| 缺点 | 原因 | 改进方向 |
|------|------|---------|
| 频率分辨率有限 | 256 点 FFT @ 1000Hz → ~3.9 Hz/bin | 增加 FFT 点数（需更多 RAM） |
| MDF 计算依赖频谱质量 | 电极接触不良时功率谱异常 | 已通过信号质量评估缓解 |
| 校准需要主动配合 | 用户需完成 10s 放松 + 15s 最大收缩 | 可考虑无校准模式 |
| 单通道 sEMG | 仅采集一块肌肉 | 硬件扩展（多路 ADC） |
| 疲劳度需主观验证 | MDF 下降与主观疲劳的相关性 | 下一步：招募受试者做对照实验 |
| UNO R4 WiFi 算力限制 | 无法运行更复杂的频域特征 | 升级到 STM32 或 ESP32 |

### 5.3 方法学说明与适用范围

**锚点公式的学术定位**：
本算法的锚点归一化公式 `F = (activeMDF - curMDF) / (activeMDF - relaxMDF) × 100%` 是基于 MDF 疲劳下降原理的**创新适配**，而非直接引用某篇论文的标准方法。文献中常用的标准方法包括：
- MDF 斜率法：对 MDF-t 做线性回归，斜率为负表示疲劳（Merletti 1990; Cifrek 2009）
- MDF 归一化比值：MDF(t) / MDF(初始值)，观察比值随时间下降（González-Izal 2012）
- 本算法采用双锚点归一化是针对嵌入式实时场景的工程适配，消除了动态基线捕获时机的不确定性

**MDF 线性下降的适用条件**：
文献确认"MDF decreases linearly over time"（Frontiers 2022），但该结论**主要基于等长收缩（isometric contraction）实验**。本算法在以下场景中的可靠性：
- 等长收缩（如握力保持）：可靠性高 ✅
- 低动态收缩（如缓慢反复抓握）：可靠性中等 ⚠️
- 高动态运动（如快速挥臂、跑步）：可靠性低，需时频分析方法 ⚠️

**力混杂效应的已知局限**：
MDF 不仅随疲劳变化，也随收缩力水平变化（Phinyomark 2012 综述了三种矛盾结论：CF1 无关 / CF2 正相关 / CF3 负相关）。本算法通过 RMS 趋势交叉验证缓解此问题，但无法完全消除。建议用户在监测期间**保持稳定的收缩力度**以获得准确的疲劳度读数。

**放松恢复模型的依据**：
放松时采用指数衰减恢复（半衰期 ~35s），基于 Elfving et al. (2002) 对 55 名受试者的 MDF 恢复研究（r²=0.98）。该模型比纯 Hold（永不恢复，高估疲劳）和快速衰减（3s 归零，丢失疲劳状态）更符合生理学。

**单特征局限与多特征趋势**：
本算法仅使用 MDF 单一频域特征。最新研究趋势是多特征融合（如 Miaoulis et al. 2025 使用 8 特征 + PCA + RF，R²=0.52）。受 RA4M1 算力限制，本算法通过 RMS 趋势交叉验证作为轻量化的双特征互补方案。

## 附录：核心公式汇总
| 符号 | 公式 | 说明 |
|------|------|------|
| RMS | $\sqrt{\frac{1}{N}\sum_{i=0}^{N-1}(x[i]-DC_{bias})^2}$ | 肌肉激活强度（mV） |
| MDF | $\int_{f_{min}}^{MDF} P(f)\,df = \frac{1}{2}P_{total}$ | 频谱中心频率（Hz） |
| 激活度 A | $A = \mathrm{clamp}\!\left(\frac{RMS - RMS_r}{RMS_a - RMS_r}\times 100,\ 0,\ 100\right)$ | 归一化收缩强度（%） |
| 疲劳度 F | $F = \mathrm{clamp}\!\left(\frac{MDF_a - MDF_{cur}}{MDF_a - MDF_r}\times 100,\ 0,\ 100\right)\times S_{force}$（收缩中），$F\times 0.998$（放松时） | 基于 MDF 下降的疲劳指数（%），动态锚点更新，力交叉验证，指数恢复 |
| 疲劳度平滑 | $F(t) = F(t-1)\times 0.7 + \max(F_{raw}(t),\ 0)\times 0.3$（收缩时），$F(t) = F(t-1)\times 0.998$（放松时） | EMA 平滑（α=0.3）+ 指数恢复（half-life≈35s），f_raw≥0避免负值 |
| 力稳定性 | $S_{force} = 1 - \mathrm{clamp}\!\left(\frac{\left|\frac{RMS}{RMS_{trend}}-1\right|-0.15}{0.35},\ 0,\ 0.7\right)$ | 力变化时降低疲劳置信度 |

注：RMS_r = 放松状态 RMS，RMS_a = 主动收缩 RMS，MDF_r = 放松 MDF，MDF_a = Active 峰值 MDF，N = 256，RMS_trend = RMS 慢速 EMA（α=0.03）。
