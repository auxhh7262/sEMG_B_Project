## 其他免费合法途径（无需发邮件）
1. **学校/单位图书馆 VPN**：有订阅则直接点 DOI 下 PDF（最省事）：
   - [4] https://doi.org/10.1016/j.clinbiomech.2009.01.010
   - [5] https://doi.org/10.1016/j.jelekin.2012.02.019
   - [6] https://doi.org/10.1007/s00421-002-0685-2
   - [3] https://onlinelibrary.wiley.com/doi/book/10.1002/0471675801
2. **文献传递（多数高校免费额度）**：国家科技图书文献中心 NSTL https://www.nstl.gov.cn/ ，或本校图书馆「文献传递/馆际互借」。
3. **ResearchGate / Academia.edu**：搜论文标题 → 关注通讯作者主页 → 有 "Download" 即作者合法自传（需登录，免费）。
4. **[3] 图书借阅**：本校/市图书馆纸质或电子借阅（WorldCat 查馆藏 https://www.worldcat.org/ ）。
